## 八、填写模板（复制即用）

**加一个 PDF**：先把文件放进 `assets/pdfs/<模块>/`，再改对应位置：

```json
{ "id": "diet-pdf-2", "title": "这里写卡片标题", "url": "assets/pdfs/diet/文件名.pdf" }
```

**加一个视频**：封面图放进 `assets/videos/<模块>/`：

```json
{
  "id": "diet-vid-2",
  "title": "视频标题",
  "cover": "assets/videos/diet/封面.png",
  "author": "作者/出处",
  "intro": "一句话简介",
  "url": "https://mp.weixin.qq.com/s/xxxx"
}
```

规则提醒：

- `title` 和 `url` **两个都填**才会显示卡片；任一为空，卡片不显示
- 视频建议用外链（公众号 / B 站），不要把大视频文件传进仓库
- `<模块>` 只能是：`diet` `exercise` `sleep` `screen` `habits` `mental` `loop` `action`
